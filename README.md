# PebbleConduct - Pebble Watch App for train conductors

So you work for a railway company that doesn't have their own smartwatch app, or you do and you prefer the Pebble?  
In that case welcome! 

PebbleConduct is a Pebble watch app designed with professional train use in mind. It will provide you real time information about your train wherever you are. It is designed to be linked to a platform that has all train path info to get position data and next commercial stop info shown. This allows you to keep an eye on the train's progress and inform passengers at a glance. 

While the app is made for professional use we did add open data sources for train enthusiasts to use it as well! 
While we probably won't add data and features useful as a passenger we don't want to leave you without the fun of using it to see if you will be on time today ;)
## Features

- Main view with clock and train info (next stop, delay, etc.)
- Train route view with stops and signaling points
- Configurable update intervals and data sources
- Long hold middle button for a Zp9 (please consult your departure procedure handbook before use, intended as a joke to make NMBS Linda relliable again)

## Data sources

- Train Charter Services employee portal (ask Maartje for more info on setup) & provided emulators 
- DB RIS - needs API key
- NS - needs API key
- [whereisthe.es](https://whereisthe.es/) - crowd sourced data on the European Sleeper trains
- Your preffered data source next? PRs are welcome!

## What's next?

The first version is a quick prototype to get the feel in the field how it works best. 

Future versions will have an improved UI, more data, more sources and more features.
